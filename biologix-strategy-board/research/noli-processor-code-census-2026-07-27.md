> Public code verifies named payment integrations—and some active Reta-cart method IDs—but not the merchant's contractual processor/ISO/acquirer chain or successful settlement.

## What each evidence status means

- `active_for_reta_cart_api`: public cart API returned the exact method ID after an anonymous Reta cart add.
- `configured_not_active_for_reta_cart`: code/config exposed the identifier, but it was not active for that tested Reta cart.
- `installed_or_code_exposed_activation_unknown` / `installed_plugin_signal_activation_unknown`: script, SDK, stylesheet, plugin, or code token observed; activation unknown.
- `historical_failed_or_shut_down_code_comment` / `planned_placeholder_not_active` / `configured_disabled_in_public_code`: public code itself says the provider is historical, planned, failed, shut down, unavailable, or disabled.
- `public_claim_or_logo_only` / `visible_first_party_language_activation_unknown`: visible claim or logo only.

No account, PII, checkout submission, order, payment attempt, credential, transaction, or gate bypass was used.
