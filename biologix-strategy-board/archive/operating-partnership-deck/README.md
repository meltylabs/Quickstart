## Controls

- Right arrow, down arrow, Page Down, or Space: next slide
- Left arrow, up arrow, or Page Up: previous slide
- Home / End: first / last slide
- `N`: presenter notes
- `O`: overview
- `F`: fullscreen
- Bottom progress segments: jump to a slide
- Print control: print or save to PDF

At 700px and below, the deck becomes a readable stacked memo with per-slide presenter-note disclosures.
