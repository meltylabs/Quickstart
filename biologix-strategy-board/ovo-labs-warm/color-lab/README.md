# Peptide homepage color lab

Internal comparison prototype for four complete homepage directions:

- A: Gilded Clinical
- B: Cobalt Standard
- C: Black Label
- D: Oxblood Editorial

The package is self-contained. From `biologix-strategy-board/ovo-labs-warm`, serve the
directory over HTTP and open `/color-lab/`.

`Standard Peptide Labs` is a working label for visual comparison, not a cleared brand
name. Product, inventory, lot, and company data are fictional. No order is processed.

This is an Alex-only decision prototype. Review the selected direction at desktop and
narrow widths before any public release.
