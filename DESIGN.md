# FitDrop Card — Design System

Generated by /plan-design-review on 2026-05-21. Branch: office-hours.

## Brand Identity

FitDrop Card is a streetwear hype culture app. Visual references: Hypebeast, Supreme drops,
Off-White lookbooks, Yeezy season cards. The aesthetic is editorial, dark, intentional —
not a SaaS dashboard. Every screen should feel like a limited-edition drop announcement.

## Typography

**Display / Headlines:** Bebas Neue (Google Fonts)
- Item names on FitDropCard, IntroScreen headline, LoadingState text
- Letter-spacing: 0.02em to 0.04em (condensed grotesque — do NOT kern too tightly)
- Never use Bebas Neue for body text, labels, or anything below 24px on web UI elements
- Exception: FitDropCard footer wordmark at 18–24px is canvas output only — not a web element

**UI / Body:** Inter (Google Fonts)
- All body text, button labels, step indicators, vote counts, form inputs
- Weights: 400 (body), 500 (labels), 600 (semi-bold UI text)

**Import:**
```css
@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Inter:wght@400;500;600&display=swap');
```

**html2canvas guard:** Always call `await document.fonts.ready` before triggering canvas capture in FitDropCard. Custom fonts do not render in html2canvas without this.

**html2canvas cross-origin guard:** All images rendered on the card (try-on photo, garment source) must be loaded with `crossOrigin="anonymous"` and served with `Access-Control-Allow-Origin: *`. Without this, html2canvas produces a blank/tainted canvas in production.

**html2canvas scale:** Pass `{ scale: window.devicePixelRatio || 2 }` to html2canvas. On a 390px viewport, the card DOM element must be rendered at 1080px wide in a hidden container — do not render at viewport width and upscale (produces blurry output).

**Forbidden:** system-ui, -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Inter as display font. These are the "I gave up on typography" signal.

## Color System

```css
:root {
  /* Backgrounds */
  --color-bg:              #0a0a0a;  /* app background, card background */
  --color-surface:         #111111;  /* modals, elevated surfaces, skeletons */
  --color-border:          #222222;  /* dividers, input outlines, subtle edges */

  /* Text */
  --color-text-primary:    #f5f5f5;  /* headings, primary content */
  --color-text-secondary:  #a3a3a3;  /* subtext, labels, step dots inactive */

  /* Accent */
  --color-accent:          #f59e0b;  /* amber — FitDrop wordmark, CTA buttons, active step dots */
  --color-accent-dim:      #92400e;  /* disabled/dimmed accent state — use as background fill only, NEVER as text color (contrast ratio ~2:1 on --color-bg) */

  /* Vote */
  --color-cop:             #16a34a;  /* green — COP button, cop count */
  --color-drop:            #dc2626;  /* red — DROP button, drop count */

  /* Animation */
  --ease-out-standard:     cubic-bezier(0.16, 1, 0.3, 1);
}
```

**Forbidden:** Purple, indigo, violet, or blue-to-purple gradients. Decorative blobs or
wavy SVG dividers. Any color not in the system above without explicit design review.

## Layout

### FitDropCard (1080×1920 canvas — html2canvas output)
- Photo: top 80% (~1536px) — full-bleed, no border-radius on the photo
- Footer: bottom 20% (~384px) — `--color-bg` background
  - Item name: Bebas Neue, ~72–96px, `--color-text-primary`, truncate at 2 lines
  - QR code: 96px × 96px, bottom-right of footer, dark squares on `--color-bg` background (NOT transparent — html2canvas renders transparency as black)
  - FitDrop wordmark: bottom-left of footer, Bebas Neue, `--color-accent` (#f59e0b), 18–24px
  - "SCAN TO COP OR DROP": Inter 400, 14px, `--color-text-secondary`, above QR code

### VotePage
- Full-screen dark layout (`--color-bg`)
- Card image: top ~60% of viewport (not full-bleed — needs room for vote UI below)
- Item name: Bebas Neue, 32px, below image
- Vote count display: Inter 500, 16px, `--color-text-secondary`, between image and buttons
- Cop/Drop buttons: equal size, side by side, 56px height (touch target), rounded-none or minimal radius
  - COP: `--color-cop` background, white text, "COP 👟" label
  - DROP: `--color-drop` background, white text, "DROP ❌" label
  - In-flight (POST in progress): both buttons disabled, amber spinner overlay, opacity 0.7
  - Disabled (post-vote): `--color-surface` (#111111) background, `--color-text-secondary` check icon on voted button
  - **Touch target: 56px height, full-width minus 16px padding each side, 8px gap between buttons**
  - Minimum 44px touch target required (WCAG 2.5.5)

### Upload Flow
- Step progress: 3 dots centered in header, 8px diameter
  - Active: `--color-accent` fill, no outline
  - Completed: `--color-text-secondary` fill, no outline
  - Upcoming: `--color-border` fill, `--color-text-secondary` outline
- Screens: full-height dark layout, content centered vertically on mobile

## Animations

| Element | Animation | Duration | Easing |
|---|---|---|---|
| TryOnResult reveal | fade-in + scale 95%→100% | 300ms | `--ease-out-standard` |
| IntroScreen exit | fade-out opacity→0 | 400ms | ease-in |
| VoteShareBadge appear | slide-up 60px + fade-in | 250ms | `--ease-out-standard` |
| VotePage loading skeleton | pulse opacity 0.4→0.8 | 1.2s | ease-in-out, infinite |
| LoadingState text | opacity loop 0.4→1 | 1.6s | ease-in-out, infinite |

All animations must include `@media (prefers-reduced-motion: reduce)` fallback: instant state change, no motion.

## Components (key visual specs)

### IntroScreen
- Full-screen: `--color-bg` background
- Headline: "Drop Alert." in Bebas Neue, 72px+, `--color-text-primary`, centered
- Subtitle: "Try on your next fit before it ships." in Inter 400, 18px, `--color-text-secondary`
- No logo, no nav, no other chrome
- Timer: 3 seconds, tap anywhere to dismiss early

### LoadingState
- Full-screen: `--color-bg` background
- Text: "DROPPING IN..." in Bebas Neue, 48px+, `--color-text-primary`, centered
- Sub-text: "Dropping in your [item name]..." in Inter 400, 16px, `--color-text-secondary`
- Animation: opacity pulse loop (not a spinner, not a progress bar, not a numeric countdown)

### VoteShareBadge
- Appears immediately after successful vote POST
- Shows: try-on image thumbnail (64px circle), item name, share button
- COP copy: "I'd COP this — [item name]" with `--color-cop` accent
- DROP copy: "I'd pass on this — [item name]" with `--color-drop` accent
- Share button uses `useShare` hook (OS share sheet on mobile, download+clipboard on desktop)

## Interaction States

**Focus-visible:** Use `outline: 2px solid var(--color-accent); outline-offset: 2px` on all interactive elements for keyboard navigation. Never suppress focus without a replacement (WCAG 2.4.7).

**Hover states (deferred to implementation):** Opacity-based hover (0.85) is acceptable for buttons. No hover spec is defined yet — implementers should use judgment. Do not invent new colors outside the system.
